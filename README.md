# שטחלה - FIELD TASK ENGINE

MVP מקומי ליצירה, ביצוע וקבלת משימות שטח, ללא שרת נתונים וללא חשבון למבצע.

## מה עובד בגרסה הזו

- ממשק מנהל: יצירה, עריכה ושמירה מקומית של תבניות.
- הפקת קובץ משימה `.ftask` וייבואו בחזרה לאפליקציה.
- Runtime נייד למבצע: פעולה אחת בכל מסך, שדות חובה, צילום, GPS וחתימה.
- טיוטה מקומית ב-IndexedDB ושמירת אחסון מתמשך כשדפדפן מאפשר זאת.
- יצירת `.fresult` אחד: PBKDF2-SHA-256 עם 250,000 איטרציות ו-AES-256-GCM.
- פתיחת תוצאה עם בדיקת hash לפני פענוח. קוד שגוי או קובץ פגום לא חושפים מידע חלקי.
- Share Sheet כאשר הדפדפן תומך בו; אחרת הורדת קובץ.
- דוח מקומי, הדפסה ל-PDF וייצוא CSV הנפתח ב-Excel.

## הפעלה נכונה

יש להגיש את התיקייה דרך HTTPS או `localhost`. אל תפתח את `index.html` ישירות מהקבצים: Web Crypto, Service Worker ויכולות שיתוף עלולות להיות חסומות.

לפיתוח מקומי:

```bash
python3 -m http.server 4173 --directory field-task-engine
```

ואז פותחים `http://localhost:4173`.

## לפני פיילוט אמיתי

הקוד מוכן לבדיקת פונקציונליות, אבל לא נכון להכריז עליו מוכן לשטח לפני ארבע בדיקות פיזיות:

1. 35 תמונות מקוריות במכשיר Android וב-iPhone.
2. שיתוף קובץ כבד דרך Safari iOS והגעתו המלאה.
3. שליחת `.fresult` ב-WhatsApp **כמסמך** ובדיקת hash בצד המקבל.
4. שרידות טיוטה ב-iOS אחרי סגירת Safari.

אלה שערי ה-GO/NO-GO שמופיעים באפיון; אי אפשר לאמת אותם באופן אמין בסביבת פיתוח שולחנית.
