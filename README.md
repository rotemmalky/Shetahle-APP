# שטחלה — ניהול משימות בשטח

אפליקציית PWA (מתקינה) לבניית תיקי-אתר, הפקת קובץ עצמאי למבצע, ופתיחת/עריכת תוצאות. הכול מקומי, בלי שרת.

## מבנה
```
shtachla/
├── index.html              עמוד הבית + מסך פתיחה (splash)
├── app.js                  לוגיקה: דשבורד, בונה משימה, תבנית תיק-אתר, עריכת תוצאה, ייצוא לסקיל
├── styles.css              מערכת עיצוב (נייבי + ליים→ציאן)
├── runner-template.html    מנוע המבצע — מוטמע בכל קובץ משימה שמופק
├── manifest.webmanifest    הגדרות התקנה
├── sw.js                   Service Worker — עבודה אופליין אחרי התקנה
├── icons/                  אייקוני האפליקציה (מהלוגו החדש)
└── README.md
```

## העלאה ל-GitHub Pages
1. ריפו חדש → העלה את תוכן התיקייה הזו לשורש.
2. Settings → Pages → Deploy from branch → main / root.
3. אחרי דקה: `https://<user>.github.io/<repo>/`

## התקנה על הטלפון
- **אנדרואיד (Chrome):** תפריט → "התקן אפליקציה" (או הבאנר שקופץ).
- **אייפון (Safari בלבד):** שיתוף → "הוסף למסך הבית".

אחרי התקנה — אפשר למחוק את הריפו (עם אזהרה: ב-iOS עדיף להשאיר כמה שבועות, Safari מנקה נתונים לא-פעילים).

## שימוש
1. "תבנית: תיק אתר" → מלא פרטי פרויקט → הגדר כמות מצלמות מכל סוג (4K/PTZ/LPR/DOME).
2. "הפקת קובץ למבצע" → נוצר קובץ HTML אחד (עמוד תיעוד אוטומטי לכל מצלמה).
3. שלח בוואטסאפ **כמסמך**. המבצע פותח (אם לא נפתח ישירות ב-iOS — שומר ופותח מ"קבצים"/Safari), ממלא, עובר "סקירה אחרונה", ושולח בחזרה + קוד 4 ספרות אופציונלי בטלפון.
4. "פתיחת תוצאה" → הזן קוד → **עריכה מלאה** (טקסט, מחיקת/הוספת תמונות).
5. "ייצוא לסקיל" → קובץ HTML עם דוח קריא + JSON מוטמע (`<script id="shtachla-data">`) → מזין לסקיל של אסי בקלוד.

## סכימת ה-JSON לסקיל
בתוך קובץ הייצוא לסקיל יש בלוק:
```html
<script id="shtachla-data" type="application/json">
{ "title", "site", "completedAt", "answers": [ { "fieldId","label","section","type","answer" } ] }
</script>
```
`type`: text/textarea/number/yesno/select/date/photo(מערך base64)/gps(אובייקט)/signature(base64). הסקיל קורא את הבלוק הזה ישירות.

## נבדק
זרימה מלאה על file:// (כמו קובץ מוואטסאפ): תבנית תיק-אתר עם ייצור מצלמות, מילוי, סקירה אחרונה, קוד, תוצאה, עריכה אצל אסי, וייצוא לסקיל — ללא שגיאות. כולל נפילה חלקה כשהצפנה לא זמינה, ומצב אופליין.

## עדיין לא נבדק
פתיחת קובץ מוואטסאפ ישירות על אייפון אמיתי — שער GO/NO-GO. בדוק על מכשיר אמיתי לפני שימוש.
