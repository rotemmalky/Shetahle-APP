# שטחלה — ניהול משימות בשטח

אפליקציית PWA שניתן להתקין על הטלפון. בונים תיק אתר, מפיקים קובץ עצמאי למבצע, ופותחים ועורכים תוצאות שחזרו מהשטח.
הכול מקומי — בלי שרת, בלי חשבון, בלי ענן. עיצוב כהה בהשראת monday.com; מנוע המבצע בעיצוב בהיר (קריא בשמש), באותה שפה עיצובית.

## 6 קבצים בלבד, כולם טקסט
```
index.html              עמוד הבית (הלוגו והפונט מוטמעים בפנים)
app.js                  לוגיקה: בית, ספריית תוצאות, אשף תיק-אתר, בונה משימה, עריכת תוצאה, ייצוא לסקיל
styles.css              עיצוב כהה + פונט עברי (Heebo) מוטמע כ-base64
runner-template.html    מנוע המבצע (עיצוב בהיר) — מוטמע בכל קובץ משימה שמופק
manifest.webmanifest    הגדרות התקנה (האייקונים מוטמעים בפנים כ-base64)
sw.js                   Service Worker — עבודה אופליין אחרי התקנה
```
**אין אף קובץ PNG.** כל האייקונים והפונט מוטמעים בתוך הקבצים — כדי שההעלאה ל-GitHub לא תישבר ולא ייעלמו קבצים.

## העלאה ל-GitHub Pages
1. בריפו: **מחק את כל הקבצים הקיימים** (כדי שלא יישארו שאריות מגרסה ישנה — חשוב במיוחד הפעם, כי גרסת ה-Service Worker התחלפה).
2. Add file → Upload files → גרור את **כל 6 הקבצים יחד** לשורש הריפו.
3. Commit.
4. Settings → Pages → Deploy from a branch → main / (root).
5. אחרי דקה: `https://<user>.github.io/<repo>/`

## התקנה על הטלפון
- **אנדרואיד (Chrome):** תפריט ⋮ → "התקן אפליקציה", או הבאנר שקופץ באפליקציה, או "עוד" ← "התקנת האפליקציה".
- **אייפון (Safari בלבד):** כפתור שיתוף → "הוסף למסך הבית".

### אם ראית גרסה ישנה / אייקונים שבורים
ה-Service Worker שומר עותק מקומי (גרסה `shtachla4-v1` — עודכנה בגרסה הזו כדי לאלץ רענון אוטומטי אצל משתמשים שכבר התקינו). אם עדיין רואים גרסה ישנה: באתר → לחץ על ה-🔒 ליד הכתובת → הגדרות אתר → מחק נתונים → סגור את הטאב ופתח מחדש.

## שימוש
1. **בית** → FAB (➕) או כרטיס "התחלה" → **תיק אתר חדש** (אשף 4 שלבים: פרטים → מצלמות → שדות נוספים → סקירה+הפקה), או **משימה מאפס** (מסך יחיד).
2. בשלב השדות אפשר לערוך כל שדה בחלונית תחתונה: נוסח, סוג, **אפשרויות בחירה, טקסט עזרה**, שם סעיף, חובה/רשות, מחיקה.
3. **הפקת קובץ למבצע** → קובץ HTML אחד, עם עמוד תיעוד אוטומטי לכל מצלמה (שם, גובה התקנה, תמונת מצלמה, תמונת אזור עניין, הערה). התמונות נדחסות אוטומטית (עד 1920px, JPEG) לפני שהן נשמרות — כך שקובץ טיוטה של סיור מלא לא ימלא את האחסון של המבצע באמצע העבודה.
4. שלח בוואטסאפ **כמסמך** (לא כתמונה). המבצע פותח, ממלא, עובר **מסך סקירה אחרונה** (עריכת שדה בודד חוזרת ישירות לסקירה — לא מכריחה לעבור שוב על כל השלבים), ושולח בחזרה + קוד 4 ספרות אופציונלי שנמסר בטלפון.
5. **תוצאות** → פתיחת תוצאה → הזן קוד אם צריך → התוצאה נשמרת בספריית התוצאות באפליקציה (לא רק בקובץ) → כרטיס התקדמות עם סעיפי אתר, עריכה מלאה (טקסט, הוספה/מחיקה של תמונות), ייצוא ל-PDF / Excel / לסקיל.
6. **ייצוא לסקיל** → קובץ HTML עם דוח קריא + JSON מוטמע → מזינים לסקיל בקלוד שמייצר את המסמך הסופי.

## סכימת ה-JSON לסקיל
בקובץ הייצוא יש בלוק:
```html
<script id="shtachla-data" type="application/json">
{ "title", "site", "completedAt",
  "answers": [ { "fieldId", "label", "section", "type", "required", "answer" } ] }
</script>
```
`type` אפשריים: `text` / `textarea` / `number` / `yesno` / `select` / `date` / `photo` (מערך base64) / `gps` (אובייקט lat/lng/accuracy) / `signature` (base64).
`required` נוסף בגרסה הזו כדי שדוחות שנבנים על הסכימה יוכלו להבחין בין שדה חסר-חובה לשדה חסר-רשות.
הסקיל קורא את הבלוק הזה ישירות — בלי לנתח טקסט.

## מה נבדק
בדיקה אוטומטית אמיתית (לא קריאת קוד) — מריצים את האפליקציה בדפדפן וירטואלי, לוחצים כפתורים, ממלאים טפסים, ובודקים את מה שבאמת קרה במסך:
- **האפליקציה הראשית:** בית ריק/מלא, אשף תיק-אתר על 4 השלבים, מונה מצלמות, חלונית עריכת שדה (כולל אפשרויות בחירה וטקסט עזרה), הוספה/מחיקה של שדות, הפקת קובץ, ייבוא משימה חזרה (משחזר סוג+מצלמות+שדות גולמיים במדויק), ייבוא תוצאה לספרייה, כרטיס התקדמות.
- **מנוע המבצע:** מסך פתיחה, מעבר בין 24 שדות (כולל ולידציה לשדה חובה ריק), תמונה — הוספה ומחיקה, חתימה, GPS, מסך סקירה ועריכה-וחזרה-לסקירה, שמירת טיוטה אוטומטית כולל באנר כשל כשהאחסון נכשל, יצירת קובץ תוצאה.
- **קובץ התוצאה:** גרסה פתוחה (ללא קוד) וגרסה נעולה — כולל דחיית קוד שגוי בלי חשיפת מידע, ופתיחה נכונה עם הקוד הנכון, דרך המסך האמיתי (לא הדמיה של ההצפנה).
- כל קובץ תוצאה עובר דרך `file://` בדיקה (בדיוק כמו קובץ שהורד מוואטסאפ).
- ה-`</script>` שבתוך קובץ התוצאה המוטמע נבדק שלא שובר את הקובץ המכיל (זו הייתה תקלה אמיתית שנתפסה ותוקנה במהלך הבדיקה).

## מה עדיין לא נבדק
**פתיחת קובץ מוואטסאפ ישירות על מכשיר אמיתי (אייפון/אנדרואיד).** בדיקה אוטומטית מדמה דפדפן, אבל לא מחליפה בדיקה על מכשיר אמיתי — שלח קובץ בדיקה קטן לאייפון ולאנדרואיד וּודא שהוא נפתח ורץ. אם באייפון לא נפתח ישירות: לשמור את הקובץ ולפתוח מ"קבצים" או מ-Safari.
